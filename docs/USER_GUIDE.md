## ขั้นตอนการเริ่มต้นใช้งาน

### ขั้นที่ 1 — ตั้งค่าทีมและผู้ใช้งาน

1. ไปที่ **ตั้งค่า → จัดการทีม** → กด "เพิ่มทีม" → กำหนดชื่อทีมและหัวหน้าทีม
2. ไปที่ **ตั้งค่า → จัดการผู้ใช้** → กด "เพิ่มผู้ใช้" → กรอกชื่อ, email, role (Staff/Supervisor)
3. แจ้ง password ชั่วคราวให้ Staff เปลี่ยนเมื่อ login ครั้งแรก

### ขั้นที่ 2 — เพิ่มข้อมูลลูกค้า

1. ไปที่เมนู **ข้อมูลบริษัท** → กด "เพิ่มบริษัท/ห้างหุ้นส่วนฯ"
2. กรอกข้อมูลที่จำเป็น:
   - **ชื่อบริษัท/ห้างหุ้นส่วนฯ** (บังคับ)
   - **ประเภทธุรกิจ** (บังคับ)
   - **วันสิ้นรอบบัญชี** เช่น 31/12 (บังคับ)
   - **ประเภทภาษี** ที่ต้องยื่น เช่น ภ.ง.ด.1, ภ.พ.30, ภ.ง.ด.50 (บังคับ อย่างน้อย 1 ประเภท)
3. กด "เพิ่มบริษัท/ห้างหุ้นส่วนฯ"

> กด **"ตั้งค่าเพิ่มเติม"** เพื่อกำหนดเลขนิติบุคคล, วิธียื่น, ผู้รับผิดชอบ และทีม

### ขั้นที่ 3 — งานจะถูกสร้างอัตโนมัติ

- ระบบสร้างงานให้ **ทุกคืน 01:00 น.** โดยอัตโนมัติ หลังจากเพิ่มลูกค้าและกำหนดประเภทภาษีแล้ว
- Supervisor สามารถกด **"สร้างงานทันที"** ในหน้างาน เพื่อไม่ต้องรอถึงวันถัดไป
- งานแต่ละรายการ **ไม่ถูกสร้างซ้ำ** — สร้างกี่ครั้งก็ได้ผลเหมือนกัน

### ขั้นที่ 4 — ติดตามและอัปเดตงาน

**หน้างาน (`/tasks`)**

- เห็นงานทั้งหมดของตัวเอง (Staff) หรือทุกคน (Supervisor)
- กรองได้ตามสถานะ / เดือน / ปี / ผู้รับผิดชอบ
- **อัปเดตสถานะเร็ว:** กดที่ badge สถานะในตาราง → เลือก "เริ่มดำเนินการ" หรือ "ยืนยันยื่นแล้ว" ได้เลย
- **ดูรายละเอียด:** กดปุ่ม "ดู" → เปิด popup อัปโหลดหลักฐาน เพิ่มหมายเหตุ ดูประวัติ

**สถานะงาน:**

| สถานะ | ความหมาย |
|-------|---------|
| รอดำเนินการ | งานยังไม่ได้เริ่ม |
| กำลังดำเนินการ | Staff รับงานแล้ว กำลังดำเนินการ |
| ยื่นแล้ว | ยื่นแบบเสร็จสิ้น |
| เกินกำหนด | ยังไม่เสร็จและเลยวันครบกำหนด |

## การรับแจ้งเตือนผ่าน LINE

ระบบส่งแจ้งเตือนอัตโนมัติผ่าน LINE ดังนี้:

| เวลา | การแจ้งเตือน |
|------|------------|
| 08:00 น. | แจ้งเตือนงานที่ครบกำหนดใน **5 วัน** |
| 08:00 น. | แจ้งเตือนงานที่ครบกำหนด **พรุ่งนี้** + แจ้งหัวหน้าทีม |
| 09:00 น. | แจ้งเตือนงาน **Overdue** ทั้งหมด |

### วิธีผูก LINE Account

1. Login เข้าระบบ → ไปที่เมนู **โปรไฟล์**
2. กดปุ่ม **"สร้างโค้ด"** → ระบบแสดงรหัส 6 หลัก (ใช้ได้ภายใน 10 นาที)
3. เปิด **LINE** → ค้นหา LINE Official Account ของสำนักงาน
4. พิมพ์ข้อความในรูปแบบ:

   ```
   MALI 123456
   ```

   (แทน `123456` ด้วยรหัสที่ได้จากระบบ)

5. รับข้อความยืนยัน → ผูก LINE สำเร็จ

**ทดสอบการเชื่อมต่อ:** พิมพ์ `test` ใน LINE OA → ถ้าได้รับข้อความตอบกลับ แสดงว่าเชื่อมต่อสำเร็จ
